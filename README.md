# EntityForge

**Corporate Entity & Milestone Tracker**

A professional operational management tool designed for holding companies to track subsidiaries, manage rebranding & digital transformation projects, monitor milestones, and handle committee documents.

## Features

- **Subsidiary Management** – Full CRUD for corporate entities
- **Project Tracking** – Rebranding, Digital Implementation, and other project types
- **Milestone Timeline** – Visual month-based timeline with progress tracking
- **Document Portal** – Simulated secure document management for committees
- **Role-Based Access** – Admin, Committee Member, and Viewer roles
- **Form Validation** – Robust validation using Zod + React Hook Form
- **Nested Data Structure** – Clean handling of complex hierarchical data

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui
- Zustand (with localStorage persistence)
- React Hook Form + Zod
- date-fns
- Lucide React
